# Installation

## Stable release

To install videoAgent, run this command in your terminal:

```sh
uv add python-boilerplate
```

Or if you prefer to use `pip`:

```sh
pip install python-boilerplate
```

## From source

The source files for videoAgent can be downloaded from the [Github repo](https://github.com/weiguang/video_agent).

You can either clone the public repository:

```sh
git clone git://github.com/weiguang/video_agent
```

Or download the [tarball](https://github.com/weiguang/video_agent/tarball/master):

```sh
curl -OJL https://github.com/weiguang/video_agent/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd video_agent
uv pip install .
```
